# 로케슛 펫

메타몽이 키보드 입력과 마우스 클릭에 반응하는 Windows 데스크톱 앱의 배포 저장소입니다.

**[다운로드와 설치 안내](https://wasjoy.github.io/rokeshot-pet/)**

## v0.2.1

- Windows x64 설치 파일. 무료 테스트 배포판입니다.
- 입력 반응이 기본으로 켜집니다. 사용자가 끈 설정은 유지됩니다.
- QWER / ASDF / ZXCV 키 위치에 맞춰 왼팔이 움직이고, 오른팔은 마우스 좌우 버튼에 따로 반응합니다.
- 누르고 있는 동안 자세를 유지합니다. 펫을 드래그해서 위치를 옮길 수 있습니다.
- 보라색 유리 스타일 설정 창에서 크기·표시·입력 반응을 조절할 수 있습니다.
- 메타몽이 기본 포함됩니다. 피카츄 기본 이미지 세트는 포함되지 않습니다.

[Windows 설치 파일](https://github.com/WasJoy/rokeshot-pet/releases/download/v0.2.1/Rokeshot-Pet-0.2.1-win-x64.exe) · [릴리스](https://github.com/WasJoy/rokeshot-pet/releases/tag/v0.2.1)

## 설치

1. Windows PC에서 EXE를 다운로드합니다.
2. 설치를 완료한 뒤 시작 메뉴의 **Rokeshot Pet**을 실행합니다.
3. 설정은 작업 표시줄 알림 영역의 펫 아이콘으로 다시 열 수 있습니다.
4. 완전히 종료하려면 설정의 **완전히 종료**를 누릅니다.

이 설치 파일은 코드 서명이 없습니다. Windows가 게시자를 확인할 수 없다는 경고를 표시할 수 있습니다. ARM 전용 빌드는 제공하지 않습니다.

## 검증 범위

릴리스에 `validation-report.json`과 `SHA256SUMS.txt`를 함께 제공합니다. 자동 검증 결과와 파일 무결성 확인용 해시이며, 코드 서명이나 보안 제품의 안전 인증을 의미하지 않습니다. 실제 Windows 10·11 PC에서 물리 키보드·마우스로 하는 테스트는 별도입니다.

## 개인정보

입력 이벤트는 PC 안에서 캐릭터 반응에만 사용합니다. 입력 문장·키 이력은 저장하거나 서버로 전송하지 않습니다. 캐릭터·크기·위치·입력 반응 설정과 사용자가 등록한 PNG만 PC에 저장됩니다. 로그인, 분석 SDK, 자동 업데이트는 없습니다.

이 저장소에는 공개 다운로드 페이지와 릴리스 파일만 있습니다. 앱 소스는 별도로 관리합니다.

비공식 팬 프로젝트입니다. 포켓몬 관련 권리는 각 권리자에게 있습니다.
